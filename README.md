# 💻 Developer Portfolio Website

A sleek, premium, developer-themed portfolio website designed to look and feel like a modern code editor (IDE). It is built with vanilla HTML, CSS, and JavaScript, and is fully responsive across all device sizes.

## 🚀 Features

* **IDE-Style Layout**: Styled with file tab navigation and dynamic editor line numbers.
* **Fully Responsive**: Optimised for all screen sizes.
* **Modern Interactivity**: Features typewriter animations, scroll reveal animations, and a scroll-spy active navigation bar built using native JavaScript.
* **Contact Form**: Integrated with Formspree for direct email notifications.
