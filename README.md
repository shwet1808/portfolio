## 🚀 Features

* **IDE-Style Interface**: Designed to resemble an active developer environment, complete with code tab navigation and dynamic gutter line numbers.
* **Responsive Layout**: Fluidly optimized for all devices—from 320px mobile screens to large desktop monitors.
* **High-Performance Interactivity**: Implemented using vanilla Javascript with Intersection Observers for smooth animations, scroll-spy headers, and scroll-reveals.
* **Accessibility First**: Respects system preferences for reduced motion and keyboard navigation (`focus-visible`).
* **Operational Contact Form**: Integrates with Formspree for immediate messaging without page reloads.
